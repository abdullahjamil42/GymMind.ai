# AI Gym Coach – Complete MVP Specification (Including AI Models)

This document defines the **full MVP scope** of an AI-powered gym web application, including **page-by-page functionality**, **AI model sources**, **what is built vs integrated**, and **how AI is orchestrated**. This is written to be directly consumable by **GitHub Copilot / Cursor / IDE agents**.

---

## 0. Global Architecture & AI Philosophy

### Core Principle

* The MVP **does not train large models**
* The product **integrates pre-trained AI models + rule-based logic**
* Focus is on **AI orchestration, reasoning, and personalization**

### AI Stack Overview

| Feature             | AI Source           | Built By Us       |
| ------------------- | ------------------- | ----------------- |
| Workout plans       | LLM API             | Prompt + logic    |
| Chatbot             | LLM API             | Context injection |
| Routine analysis    | LLM API             | Fitness rules     |
| Form detection      | MediaPipe / MoveNet | Error rules       |
| Calories            | LLM + Food DB       | Estimation logic  |
| Progress prediction | Rules / regression  | Math logic        |

---

## 1. Landing Page (`/`)

### Purpose

Introduce the product and convert visitors into users.

### Functional Behavior

* Static marketing page
* No AI calls
* CTA routes to authentication

### Components

* HeroSection
* FeatureCards
* HowItWorks
* CTAButtons
* Footer

---

## 2. Authentication (`/login`, `/signup`)

### Purpose

Secure user identity and initialize AI personalization.

### Behavior

* Email/password authentication
* Create user document in database
* Redirect to onboarding

---

## 3. User Onboarding (`/onboarding`)

### Purpose

Collect **all inputs required by AI systems**.

### Inputs

* Age, gender, height, weight
* Fitness goal
* Experience level
* Training location
* Available days
* Injury flags

### Backend Logic

* Calculate BMR and TDEE
* Store profile for LLM context

### AI Usage

* No AI generation yet
* Data used later in all prompts

---

## 4. Dashboard (`/dashboard`)

### Purpose

Single control center for all AI outputs.

### Components

* TodayWorkoutCard
* CalorieStatusCard
* ProgressSnapshot
* ChatbotMiniWidget

### AI Usage

* LLM generates daily recommendation summary
* Uses workout + nutrition history

---

## 5. AI Workout Plan Generator (`/workout-plan`)

### Purpose

Generate a **scientifically structured workout plan**.

### AI Model

* **LLM API (OpenAI / Gemini / Claude)**

### Prompt Inputs

* User profile
* Goal
* Experience
* Available days
* Injury data

### Prompt Rules

* Balanced muscle groups
* Weekly volume limits
* Progressive overload logic

### Output

Structured JSON workout plan with explanations.

---

## 6. Workout Session Page (`/workout/:day`)

### Purpose

Guide user during training.

### Features

* Exercise list
* Rest timers
* Instructions
* Upload form video

### AI Usage

* LLM explains exercise intent
* Data logged for future reasoning

---

## 7. AI Exercise Form Checker (`/form-check`)

### Purpose

Detect form mistakes using video analysis.

### AI Model

* **MediaPipe / MoveNet (pre-trained)**

### Supported Exercises (MVP)

* Squat
* Push-up

### Logic Built by Us

* Extract joint keypoints
* Calculate angles
* Rule-based error detection

### Output

* Form score
* Detected issues
* Correction suggestions
